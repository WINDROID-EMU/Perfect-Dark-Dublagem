# 🎙️ PERFECT DARK - PROJETO DE DUBLAGEM

Projeto de extração, organização e redublagem dos áudios do **Perfect Dark (Nintendo 64)** para utilização no **Perfect Dark Port Android**.

Os áudios foram separados por cenas, missões, diálogos durante o jogo, treinamento e vozes de NPCs.

**Status atual do projeto:**

* Total de áudios extraídos: **548**
* Total de cenas e pastas: **60**

## 📂 Estrutura dos arquivos

* **01_Cutscenes** → Sequências cinematográficas do jogo.
* **02_Briefings_de_Missao** → Briefings narrados por Daniel Carrington.
* **03_Fases_Dialogos_InGame** → Diálogos acionados durante as fases.
* **04_Carrington_Institute_Treinamento** → Áudios do centro de treinamento.
* **05_Vozes_Genericas_e_NPCs** → Vozes e reações dos personagens secundários.

## 🎯 Objetivo

Permitir que os áudios originais do jogo sejam redublados e utilizados no port para Android, proporcionando uma experiência mais imersiva para a comunidade.
